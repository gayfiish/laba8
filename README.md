**№4. Создать CLI-утилиту с Poetry**

С помощью Poetry настроены две консольные команды:

- laba8-cli — программа приветствия;
- laba8-tasks — менеджер задач.

Менеджер задач поддерживает добавление, просмотр
и завершение задач с сохранением в JSON.

**№10. Реализовать разделение на слои сервисов и данных**

Программа разделена на три уровня:

- CLI — обработка аргументов командной строки;
- Service — бизнес-логика и проверка данных;
- Data — чтение и сохранение задач в JSON.

- pytest 8.4.2.

## Установка

Установить зависимости проекта:

```powershell
poetry install
```

## Запуск программы с argparse

```powershell
poetry run laba8-cli --name Anastasia --times 3
```

Пример результата:

```text
Hello, Anastasia!
Hello, Anastasia!
Hello, Anastasia!
```

## Работа с менеджером задач

Добавить задачу:

```powershell
poetry run laba8-tasks add "Learn Python"
```

Посмотреть задачи:

```powershell
poetry run laba8-tasks list
```

Отметить задачу выполненной (указать её номер):

```powershell
poetry run laba8-tasks done 1
```

Посмотреть справку:

```powershell
poetry run laba8-tasks --help
```

Задачи сохраняются в файле tasks.json.
Файл с пользовательскими данными исключён из Git.

## Тестирование

Запустить автоматические тесты:

```powershell
poetry run pytest -v
```

Реализовано 11 тестов, проверяющих работу сервисного
слоя и хранение данных, включая ошибочные сценарии.

Для изоляции тестов используется временная директория tmp_path.

## Проверка стиля кода

```powershell
poetry run flake8 .
```

При отсутствии ошибок команда завершается без сообщений.
